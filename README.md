# 🎮 Ayush Varma — 2D Game Portfolio

A retro Mario-style 2D side-scrolling platformer that doubles as an interactive portfolio website. Run, jump, collect coins, dodge hazards, and explore billboards showcasing my background, skills, and projects — all the way to the victory flagpole.

Built entirely with **vanilla HTML5, CSS3, and JavaScript** — no frameworks, no build tools, no dependencies. Just one self-contained `index.html` file.

## 🕹️ How to Play

| Action | Keys |
|---|---|
| Move Left / Right | `←` `→` Arrow Keys or `A` `D` |
| Jump | `↑` Arrow, `W`, or `Spacebar` |
| Double Jump | Press Jump again while airborne |

On mobile/touch devices, on-screen D-pad and jump buttons appear automatically.

### Objectives
- 🪙 Hit `?` mystery blocks from below to pop out coins
- 💰 Collect floating coins scattered across the level
- 🩹 Dodge the rolling pink/purple slime hazards — one hit ends the run
- 📋 Walk up to signboards to read portfolio info as you pass them
- 🏁 Reach the flagpole at the end to complete the run and trigger the victory celebration

## 🛠️ Tech Stack

- **HTML5 Canvas API** for rendering and the game loop (`requestAnimationFrame`)
- **Vanilla JavaScript** for physics (gravity, acceleration, friction, AABB collision), camera tracking, and game state
- **CSS3** for the retro UI overlays, HUD, and animations
- **Google Fonts** (`Press Start 2P`) for the pixel-art aesthetic

No frameworks. No build step. No package manager. It just runs.

## 🚀 Running Locally

Since it's a single static file, there's nothing to install:

1. Clone or download this repository
2. Open `index.html` directly in any modern browser

That's it — no server required for local testing.

---

## 🌐 Deployment

This project is deployed as a static site via **GitHub Pages**:

1. Push `index.html` to the `main` branch of this repo
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`
4. GitHub publishes the site at `https://<username>.github.io/<repo-name>/`

Also works out of the box on Netlify, Vercel, or any static file host.
